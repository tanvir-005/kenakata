# KenaKata.com

## Capstone Assignment --- Modern E-Commerce Storefront

Build a production-style storefront with **Next.js App Router** and the
**Platzi Fake API**. The goal is to demonstrate scalable frontend
architecture, modern Next.js patterns, and solid engineering practices.

**Submission date:** 19 May 2026

### Submission

Submit:

-   A public GitHub repository
-   `README.md`
-   Setup and environment documentation
-   A deployment URL

## Tech Stack

### Required

-   Next.js (latest stable)
-   TypeScript
-   App Router
-   Tailwind CSS

### Nice to Have

-   React Hook Form
-   Zod
-   Vitest or Jest

## API

**Base URL:** https://fakeapi.platzi.com/

You may use:

-   Products API
-   Categories API
-   Users API
-   Authentication API
